## Pré-requisitos

Certifique-se de que sua máquina possui as seguintes ferramentas instaladas:

* **GCC** 
* **Makefile** 

## Como compilar e executar

Abra o terminal no diretório principal do projeto e execute o comando abaixo:

```bash
make run
```

*Note que irá ser criado o arquivo `personagens`, portanto, caso queira remover, execute `make clean`, e para executar novamente, execute o comando acima novamente após a limpeza.*
